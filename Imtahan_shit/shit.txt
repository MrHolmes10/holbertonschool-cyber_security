Sabahkı exam üçün ən vacib şeyləri practical angle-dən keçək.

1. AD Nədir? (30 saniyə)
AD = Windows şəbəkəsindəki mərkəzi auth sistemi. Hər şey Domain Controller (DC)-dan keçir.
Forest → Domain → OU → Users/Computers/Groups
WORKGROUP ≠ DOMAIN (domain = centralized auth)
Key terminlər:

DC - hər şeyin beyni
LDAP - AD-a sorğu protokolu (port 389/636)
Kerberos - auth protokolu (port 88)
SMB - fayl paylaşımı (port 445)
RPC - uzaqdan prosedur çağırışı (port 135)


2. ENUMERATION (Ən Vacib Hissə)
Şəbəkədəsən, credentials yoxdur — Anonymous/Null Session
bash# SMB null session
enum4linux -a <IP>
enum4linux-ng -A <IP>

# NetBIOS
nbtscan <IP_RANGE>

# LDAP anonymous
ldapsearch -x -H ldap://<IP> -b "dc=domain,dc=com"

# Nmap AD portları
nmap -sV -p 88,135,139,389,445,636,3268,3389 <IP>
Credentials əlindədir — Authenticated Enum
bash# Domain info
net user /domain
net group /domain
net group "Domain Admins" /domain

# CrackMapExec (CME) - hər şey üçün
crackmapexec smb <IP> -u user -p pass --users
crackmapexec smb <IP> -u user -p pass --groups
crackmapexec smb <IP> -u user -p pass --shares
crackmapexec smb <IP> -u user -p pass --pass-pol

# LDAP ile full enum
ldapdomaindump -u 'domain\user' -p 'pass' <IP>

# RPCClient
rpcclient -U "user%pass" <IP>
  > enumdomusers
  > enumdomgroups
  > querydominfo

Sadə dillə: AD-dakı bütün məlumatları (userlər, qruplar, kompüterlər, policyler) sorğulamaq üçün istifadə edilən protokol. Düşün ki AD bir verilənlər bazasıdır, LDAP isə onun query dilidir.

Necə İşləyir?
Sən                    DC (AD)
 |                       |
 |--- LDAP query ------->|
 |    "bütün userları ver"|
 |<-- cavab (CN, DN...) --|
Port: 389 (normal), 636 (SSL/LDAPS)

Struktur
dc=thm,dc=loc                    ← Domain (thm.loc)
└── ou=Users                     ← Organizational Unit
    ├── cn=john.harris            ← User object
    │     mail: john@thm.loc
    │     memberOf: Domain Users
    └── cn=svc.jenkins            ← Service account
dc = domain component, ou = organizational unit, cn = common name — bunlar DN (Distinguished Name) hissələridir.

Praktikada
bash# Anonymous (null bind) — creds olmadan
